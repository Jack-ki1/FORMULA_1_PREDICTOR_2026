# Model Registry

Path: `training/model_registry/registry.json`

Each entry:

```json
{
  "model_id": "win-probability-v12",
  "version": "12",
  "trained_at": "2026-09-14T…",
  "training_cutoff": "2023-12-31",
  "feature_version": "feature-v8",
  "dataset_version": "dataset-v14",
  "algorithm": "ensemble_gb_rf",
  "metrics": {"log_loss":0.378,"brier":0.099,"top1":0.42},
  "status": "champion"
}
```

Champion/challenger promotion via `training/model_registry/registry.py:promote_champion`.

Artifacts in `cache/model_cache/*.pkl` + `calibrator.pkl`. Generated by `python -m training.pipelines.train` (temporal split, OOF weights, isotonic calibration). Inference loads via `ModelZoo.load_models()` lazily; if missing, prediction falls back to `statistical_fallback` and API marks `prediction_source`.

Exposed at `GET /api/v1/system/models`.
